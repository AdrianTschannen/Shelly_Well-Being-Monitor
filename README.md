This script is designed as a discreet daily well-being signal for an elderly person living alone.
Instead of actively monitoring the person with motion sensors, cameras, or other intrusive devices, it uses a normal daily routine: preparing the morning coffee.
When the coffee maker consumes enough energy, the system assumes that the person is awake and following their usual routine.
A Pushover message is then sent automatically to relatives as a simple “life sign”.
If no coffee preparation is detected by the configured morning check time, an alert is sent so that relatives can follow up.
This approach respects privacy because it does not track movement, presence, or behavior throughout the home.
It only observes a single appliance that is already part of the person’s normal morning habit.
The solution is therefore suitable for supporting independent living while keeping the monitoring as unobtrusive as possible.
Alternative sensors, such as motion detectors, could technically be used, but may be perceived as invasive surveillance.
The coffee maker provides a practical, human-friendly, and privacy-conscious trigger for daily reassurance.
